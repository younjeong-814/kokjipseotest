# 마이페이지 + 소비 완료 통합 검증

브랜치: feature/yunjeong_mypage-consumed-test_v1

- 소비 완료 작업을 stash 백업한 후 최신 마이페이지 집계 작업과 통합했다. 공통 App.tsx에는 소비 완료 콜백과 실제 대시보드 집계를 모두 유지했고, 테스트 목록에도 두 작업을 함께 포함했다.
- 테스트 202개와 TypeScript/Vite 빌드 통과.
- 실제 App 컴포넌트를 별도 5180 출처에서 실행하고 테스트 식재료 3개로 검증했다. 0% → 저장 → 확인 → 목록 제거를 각 항목에서 수행했다.
- 1개 소비 완료: 남은 카드 2개 및 분석 데이터 부족 화면 확인.
- 3개 소비 완료: 카드 0개, 마이페이지 ‘소비 3개 · 폐기 0개’, 이번 주 소비 차트 3 확인.
- 새로고침 후 이력 유지 및 기존 주간 리포트의 보관 0개/소비 3개/폐기 0개 확인.
- 테스트 데이터와 검증 전용 소스는 제거했다. 기존 5174/5175 사용자 localStorage는 변경하지 않았다.
- 관리 점수·소비율은 산식 미정으로 집계 중 표시를 유지한다.
- 커밋·푸시하지 않았으며 소비/마이페이지 원본 stash도 보존했다.
