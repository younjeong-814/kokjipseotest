# 냉장고 상태별 알림

- 첫 등록 완료 화면에서는 기존 등록 토스트 또는 인증된 이메일 알림 확인 토스트를 표시한다.
- 냉장고를 떠났다가 돌아오면 안내 팝업을 판정한다. 최초 페이지 로딩, 냉장고 내부 탭 이동, 등록 직후 이동은 재진입으로 취급하지 않는다.
- 빈 냉장고에는 안내를 표시하지 않는다. 알림 설정 조회 실패 시 수신 여부를 추정하지 않는다.
- 이메일 미인증 익명 사용자(계정 연결 전): 알림 신청 안내, 사용자별 브라우저 세션당 1회. 버튼은 기존 이메일 인증 모달을 연다.
- 이메일 인증·알림 꺼짐: 다시 켜기 안내, 사용자별 기기 현지 날짜 기준 하루 1회. CTA/스위치는 기존 RPC 성공 후에만 팝업을 닫고 확인 토스트를 표시한다.
- 이메일 인증·알림 켜짐·Google 미연결: 보관 항목 2개 이상이면 Google 연결 안내, 사용자별 브라우저 세션당 1회. 익명 계정은 기존 linkIdentity 방식을 사용한다.
- Google 연결 여부는 실제 인증 identities의 google provider로 판정한다. Google 연결만으로 이메일 알림을 자동 활성화하지 않는다.
- 등록 확인 토스트는 실제 인증된 수신 주소와 enabled 설정이 있을 때만 알림을 약속한다. Figma 6437:7576에 맞춰 “소비기한이 다가오면 알려드릴게요” 한 줄만 표시한다. 팝업 안의 실제 수신 주소는 마스킹한다.
- 노출 제한에는 사용자 ID와 날짜/표시 여부만 저장하며, 이메일 주소를 추가로 저장하지 않는다.

디자인: Figma `6436:7398`. 팝업은 기존 OverlayDialog, CTA는 ActionButton, 이메일 인증은 EmailReminderModal을 재사용한다. 발송 서버·스케줄·Google 제공자 설정은 변경하지 않는다.
