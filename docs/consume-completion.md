# 남은 양 0% 소비 완료

브랜치: feature/yunjeong_consumed_v1

- 상세에서 남은 양을 0%로 설정하고 저장하면 ‘모두 소비하셨나요?’ 확인창을 연다.
- 취소/Escape/닫기는 저장·삭제·이력을 변경하지 않는다. 슬라이더 초안은 유지한다.
- 확인하면 냉장고 목록에서 해당 항목을 제거하고 기존 ingredient-history 저장소에 consumed로 기록한 뒤 기존 목록으로 돌아간다.
- 기한 경과·상태 기록과 관계없이 사용자가 확인한 소비 완료로 기록한다. 기존 일반 삭제의 분류와 폐기 흐름은 유지한다.
- 기록 저장 실패 시 항목을 제거하지 않는다. 항목 삭제 실패 시 이전 이력을 복원한다. 이미 삭제된 ID는 다시 기록하지 않는다.
- 기존 주간 리포트가 같은 이력을 읽는다. 임시보관된 마이페이지 대시보드 작업을 복원해도 같은 저장 키로 연동할 수 있다.
- 일반 저장, 0% 저장→취소→재확인→consumed 기록 UI를 메모리 저장소에서 검증했다. 사용자 localStorage는 변경하지 않았다.
- 기한 경과/상했어요 강제 소비, 다른 항목 유지, 중복 방지, 저장 실패/롤백 테스트를 포함한 전체 테스트 201개 통과.
