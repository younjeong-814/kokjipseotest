# 메일 재접속 안내

브랜치: `feature/yunjeong_email-return_v1`

소비기한 메일 기본 링크는 `#fridge?source=email`을 사용한다. 이 값은 접속 경로 표시이며 사용자 ID나 인증 수단이 아니다.

- 일반 방문: 기존 익명 계정 생성·등록 흐름 유지.
- 메일 방문 + 유효한 세션: 기존 계정의 냉장고를 먼저 불러온다.
- 메일 방문 + 데이터 있음: 기존 화면 표시, 복구 안내 없음.
- 메일 방문 + 세션 없음: 신규 임시 계정 생성 없이 원래 브라우저 안내.
- 메일 방문 + 서버 조회 성공·빈 목록: 같은 안내 표시.
- 세션 확인·서버 조회 실패: 기존 오류·재시도 표시. 빈 목록으로 취급하지 않는다.

안내 화면에서 링크를 복사해 원래 브라우저에 붙여넣거나, 이전에 연결한 Google 계정으로 로그인할 수 있다. 알림 이메일 인증만으로는 다른 브라우저에서 기록을 복구할 수 없다. 이 안내의 로그인은 기존 계정 로그인이며 임시 데이터 자동 병합을 요청하지 않는다. 기존 설정 화면의 팀원 Google 연결·데이터 이전 기능은 유지한다.

## 배포 및 실기기 확인

로컬에서는 `#fridge?source=email&preview=email-return`로 디자인을 미리 볼 수 있다. 미리보기는 개발 환경에서만 작동하며 익명 계정을 생성하거나 실제 Google 로그인을 진행하지 않는다. '스낵바 다시 보기'로 공통 Snackbar 표시를 반복 확인할 수 있다. 배포 환경에서는 미리보기 기능이 비활성화된다.

1. PR 머지 후 Pages 배포를 확인한다.
2. 메일 템플릿이 포함된 서버 함수도 최신 코드로 배포한다. 프런트 배포만으로 기존 서버 템플릿은 바뀌지 않는다.
3. 새 메일의 링크에 `source=email`이 포함되는지 확인한다. 이미 받은 메일은 변경되지 않는다.
4. 등록했던 브라우저에서 메일 링크를 열면 재료가 보이고 복구 안내가 없는지 확인한다.
5. 다른 브라우저에서 열면 안내가 표시되는지 확인한다. 링크를 원래 브라우저에 복사하면 기존 재료가 보여야 한다.
6. 일반 주소로 처음 방문하면 복구 안내 없이 등록할 수 있어야 한다.

단위·회귀 테스트는 실제 메일 발송 및 Google OAuth 실기기 검증을 대체하지 않는다. 이번 변경에는 수동 배치 실행 버튼·실제 알림 발송·Cron 설정 변경이 포함되지 않는다.
